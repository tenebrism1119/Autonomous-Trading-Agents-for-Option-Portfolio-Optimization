# Autonomous Trading Agents for HS300 ETF Option Portfolio Optimization

Deep Reinforcement Learning approach to option portfolio management on the Chinese CSI 300 ETF options market, using 5 algorithms (A2C, DDPG, PPO, TD3, SAC).

Code accompanying the paper *"Autonomous Trading Agents for Option Portfolio Optimization: A Deep Reinforcement Learning Approach"*.

## Protocol at a glance

- **No validation set.** For every algorithm and every random seed, the model obtained at the end of training is used directly. No checkpoint selection is performed.
- **Three random seeds** (42, 123, 456). Results are reported as mean ± standard deviation, and paired *t*-tests are computed on the pooled daily returns.
- **Three configurations** reported in the paper:

| Paper section | Configuration | Training / test window | Produced by |
|---------------|---------------|------------------------|-------------|
| 4.2 | Main experiment | train 2022-07-01 – 2023-03-31 (184 d) / test 2023-04-03 – 2023-05-31 (39 d) | `walk_forward_noval.py` |
| 4.3 | Second rebalancing window | train 2023-01-03 – 2023-09-28 (182 d) / test 2023-10-09 – 2023-11-30 (39 d) | `walk_forward_noval.py` |
| 4.4 | Extended sample | train 2022-01-04 – 2023-03-31 (301 d) / test 2023-04-03 – 2023-12-29 (183 d) | `extended_noval.py` |
| 4.5 | Supplementary (American options) | single exploratory window, three reward specifications | `soybean_meal_american_options/` |

The main experiment and the second rebalancing window are two of the seven consecutive windows produced by the rolling procedure in `walk_forward_noval.py`; the remaining windows of the same rolling backtest are not reported in the paper.

## Quick Start

```bash
pip install -r requirements.txt

# Rolling out-of-sample backtest (seven windows, three seeds).
# Window indices are 0-based: index 3 is the main experiment,
# index 6 is the second rebalancing window.
python walk_forward_noval.py --windows 3 6

# Full rolling backtest (all seven windows)
python walk_forward_noval.py

# Extended-sample experiment, three seeds
python extended_noval.py

# Supplementary American-option experiment
python soybean_meal_american_options/main.py
```

Backtest outputs (`results*/`), trained model archives (`*.zip`) and the input data are **not** tracked in git; they are regenerated by running the scripts above.

## Reproducing the Reported Numbers

Three standalone scripts check the manuscript against the archived results. Their
input and output locations are configurable, so they run on any machine:

| Variable | Default | Purpose |
|----------|---------|---------|
| `PAPER_ROOT` | parent of this code directory | root of the paper workspace |
| `EXP_MAIN_DIR` | `<PAPER_ROOT>/exp1_main_experiment/results` | main experiment results |
| `EXP_SECOND_DIR` | `<PAPER_ROOT>/exp2_second_rebalancing_window/results` | second-window results |
| `EXP_EXT_DIR` | `<PAPER_ROOT>/exp3_extended_sample/results` | extended-sample results |
| `EXP_SOY_DIR` | `<PAPER_ROOT>/exp4_soybean_meal/results/results_ablation_reward` | American-option results |
| `FIG_OUT_DIR` | `<PAPER_ROOT>/figures` | output folder for redrawn NAV figures |

```bash
# Recompute TVM / MDD / Sharpe from the daily returns and print one
# PASS / DIFF line per number quoted in the paper (tables 3-9, abstract, text).
python verify_paper_numbers.py

# Recompute the descriptive statistics of tables 1-2 from the raw option data.
python verify_tables12.py

# Redraw the seven NAV figures with both benchmarks
# (buy-and-hold ETF and equal-weight option portfolio).
python plot_paper_nav_with_ew.py
```

Both checkers report `PASS` when the value recomputed from the stored results
matches the paper value within rounding tolerance, and `DIFF` otherwise.

## Pipeline Overview

| Step | Module | Description |
|------|--------|-------------|
| 1 | `data_loader.py` | Load Tushare CSV data, select 6 liquid contracts per rebalancing period |
| 2 | `pipeline.py` | Window boundaries, feature engineering, turbulence index, period slicing |
| 3 | `trading_env.py` | Build the Gymnasium trading environment |
| 4 | `walk_forward_noval.py` / `extended_noval.py` | Train A2C, DDPG, PPO, TD3 and SAC; retain the final model |
| 5 | `evaluate.py` | Compute TVM / MDD / Sharpe, aggregate across seeds, plot NAV curves |

## Data

Data source: Tushare Pro (provided as local CSV files).

- **Option daily bars**: `<DATA_ROOT>/options/daily/*.csv` (per trading day)
- **Contract info**: `<DATA_ROOT>/options/contracts/all_option_contracts.csv`
- **ETF prices**: `<DATA_ROOT>/underlyings/etf/510300.SH.csv`

`DATA_ROOT` defaults to `./data/data` and can be overridden with the `DATA_ROOT` environment variable:

```bash
set DATA_ROOT=D:\path\to\your\data\data      # Windows
export DATA_ROOT=/path/to/your/data/data     # bash
```

**Credentials.** No API token is stored in this repository. The supplementary soybean-meal script reads its (optional) Tushare token from the environment:

```bash
set TUSHARE_TOKEN=xxxxxxxx      # Windows
export TUSHARE_TOKEN=xxxxxxxx   # bash
```

## Contract Selection Logic

At each monthly rebalancing date (next trading day after option expiration):
1. Select the top-3 **call** contracts by trading value (money)
2. Select the top-3 **put** contracts by trading value
3. Sort each group by strike price
4. Assign labels: b1/b2/b3 (calls) + s1/s2/s3 (puts)

Non-turnover days carry forward the previous period's contracts.

## Trading Environment

- **State space**: `[cash] + price(×6) + holdings(×6) + indicators(×9×6)` = **67 dimensions**
  - 9 per-contract features: `exercise_price, base_p, diff_days, hv, iv, delta, gamma, vega, moneyness`
- **Action space**: `Box([-1, 1], shape=(6,))` — scaled by hmax = 30000 and floored to integer
- **Reward**: `(V_t - V_{t-1}) × reward_scaling (0.1)`, where `V_t` is the NAV net of transaction costs
- **Transaction cost**: 0.01 % per side (`buy_cost_pct` / `sell_cost_pct` = 0.0001)
- **Constraints**: long-only positions; turbulence index ≥ 90 triggers forced liquidation

## Evaluation Metrics

| Metric | Formula | Description |
|--------|---------|-------------|
| TVM | V_T / V_0 | Terminal Value Multiple (1.0 = break-even) |
| MDD | min(V_t / max(V_s) - 1) | Maximum Drawdown |
| SR | (E[r_d] - r_f) / σ(r_d) × √252 | Annualized Sharpe Ratio (r_f = 0) |

## Training Hyperparameters

| Algorithm | Timesteps | Key Parameters |
|-----------|-----------|---------------|
| A2C | 50,000 | default |
| DDPG | 50,000 | default |
| PPO | 200,000 | lr = 0.00025, batch = 128, n_steps = 2048 |
| TD3 | 50,000 | lr = 0.001, batch = 50, buffer = 100k |
| SAC | 70,000 | lr = 0.0001, batch = 50, buffer = 100k, ent_coef = auto_0.1 |
